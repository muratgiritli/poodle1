/yourpoodle/mama-bul sayfasındaki 11 adımlık "Mama Bul" sihirbazının UI'sını sıfırdan yeniden tasarla. Mevcut backend/API, filtreleme mantığı, state key'leri, sonuç sayfası yönlendirmesi ve form verisi AYNEN korunacak — sadece görsel katman değişecek.

Önce projede şu dosyaları bul: mama-bul route/page, MamaBul / MamaBulWizard component, mb-wizard-wrap CSS veya Tailwind class'ları. Mevcut 11 adımın state yapısını oku, field isimlerini değiştirme.

## Hedef
Ekteki mockup'lardaki premium mor-beyaz tasarımı birebir uygula. Şu anki düz liste görünümü (emoji + basit kart) tamamen kaldırılacak.

## Tasarım sistemi (tüm adımlar için ortak)

### Renkler
- Primary purple: #7B3FE4 (buton, seçili border, progress)
- Primary hover: #6D28D9
- Light lavender bg: #F3EFFF / #F4F0FF
- Card white: #FFFFFF
- Text primary: #1A1A2E
- Text secondary: #6B7280
- Border default: #E5E7EB
- Border selected: #7B3FE4
- Info banner bg: #F3EFFF
- Disabled button: #E2E2F0, text #9CA3AF

### Tipografi
- Google Font: "Inter" veya "Plus Jakarta Sans"
- Başlık: 28–32px, font-weight 700
- Alt metin: 15–16px, color secondary
- Vurgulu kelime mor + ince alt çizgi (ör: "yaşı nedir?", "hedefi", "alerjisi")

### Sayfa arka planı
- Tam ekran açık lavanta (#F3EFFF)
- Dekoratif soluk paw print ve dalga SVG'ler (opacity 0.08)
- Ortada max-width 920px beyaz kart, border-radius 28px, box-shadow: 0 20px 60px rgba(123,63,228,0.08)

### Ortak layout bileşenleri oluştur
1. `WizardShell` — arka plan + merkez kart
2. `WizardHeader` — sol üst "Adım X / 11" pill badge + sağ üst 11'li progress tracker
3. `ProgressTracker` — 11 daire: tamamlanan = mor + beyaz ✓, aktif = mor + numara, gelecek = gri border + gri numara
4. `StepHero` — sol metin (ikon + başlık + alt metin), sağda apricot toy poodle fotoğrafı mor daire içinde (object-fit cover, decorative heart/paw)
5. `OptionCard` — ikon kutusu + başlık + açıklama + sağda radio veya checkbox
6. `InfoBanner` — lavanta bar, info ikonu, "Birden fazla seçenek işaretleyebilirsiniz" vb.
7. `WizardFooter` — tam genişlik mor "Devam Et →" butonu; seçim yoksa disabled gri; adım 2+ için altında "← Geri dön" linki

### OptionCard davranışı
- Hover: border #C4B5FD, hafif shadow
- Selected: mor border 2px, hafif mor arka plan (#FAF5FF), radio/checkbox dolu mor
- Radio adımlar: tek seçim
- Checkbox adımlar: çoklu seçim
- Grid: 2 sütun desktop, 1 sütun mobil (<768px)
- Kart padding 16–20px, border-radius 16px

### Buton
- Devam Et: height 52px, border-radius 9999px, gradient mor, beyaz bold text
- Son adım: "Sonuçları Gör →"
- Seçim yapılmadan disabled

### Poodle görseli
- Tüm hero adımlarda aynı apricot toy poodle görseli kullan (projede varsa mevcut asset, yoksa public/images/poodle-hero.webp placeholder ekle)
- Mor daire backdrop: 220px, position absolute behind image

## Teknik uygulama

1. `steps.config.ts` (veya benzeri) dosyası oluştur — 11 adımın title, hint, options, type (radio|checkbox), layout (hero|grid), infoBanner metinleri burada tanımlı olsun.
2. Ana component tek `WizardStepRenderer` ile config'den render etsin; hardcode tekrar etme.
3. Mevcut state hook'unu (`useMamaBulWizard` vb.) kullan; sadece UI component'lerini değiştir.
4. Eski class'lar (`mb-wizard-wrap`, `mb-option`, `mb-step-pill`) yeni tasarıma taşınsın veya Tailwind'e geçirilsin — eski düz CSS kaldırılsın.
5. Animasyon: adım geçişinde hafif fade+slide (200ms).
6. Accessibility: option kartları button/role=radio|checkbox, aria-pressed, keyboard navigasyon.
7. Responsive: mobilde hero'da poodle üstte, metin altta; grid tek sütun.
8. Progress tracker mobilde yatay scroll veya sadece "Adım X/11" + ince progress bar.
