File: hooks/useNotificationsPage.ts

State:
  activeTab: NotificationTab (default "all")
  notifications: NotificationItem[] (from mock + older when loaded)
  selectedIds: Set<string>
  showOlder: boolean
  settingsModalOpen: boolean

Functions:
  setTab(tab) → filter notifications by category
  toggleSelect(id)
  selectAll() → select all VISIBLE filtered notifications
  deselectAll()
  markSelectedAsRead() → set isRead=true for selected + toast "Okundu olarak işaretlendi ✓"
  markAllVisibleAsRead() → if nothing selected, mark all visible unread as read
  clearSelected() → remove selected from list + update tabCounts + toast "Bildirimler temizlendi"
  clearAll() → remove all visible in current tab + confirm dialog
  loadOlder() → append olderNotifications + set showOlder true
  markAsReadOnClick(id) → mark single item read when row clicked
  openSettings() / closeSettings()

Computed:
  filteredNotifications → by activeTab
  groupedNotifications → group filtered by group field preserving groupOrder
  unreadCount → notifications.filter(n => !n.isRead).length
  selectedCount → selectedIds.size
  isAllSelected → all visible selected

Persist read/cleared state to localStorage key "yourpoodle-notifications" (optional).
