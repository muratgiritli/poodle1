### 1. Ürün API'si boş dönüyor — mağaza tamamen çalışmıyor
Sorun: GET /api/products → [] (boş dizi, HTTP 200)
Sayfa "0 ürün" + "Ürün bulunamadı" gösteriyor.
Hero banner "900+ Ürün" yazıyor ama hiç ürün yok.

Kök neden araştır ve düzelt:
- Veritabanında ürün var mı kontrol et
- API filtreleri (published, active, visible) ürünleri yanlışlıkla dışlıyor olabilir
- Ürün import/sync job çalışmıyor olabilir
- campaign-items API de boş: GET /api/campaign-items → []

Yapılacaklar:
- /api/products en azından yayında olan tüm ürünleri döndürmeli
- Her ürün minimum alanlar: id, name, slug, price, image, category, brand, stock, isActive
- Ürün yoksa hero'da "900+ Ürün" YAZMA — gerçek sayıyı dinamik göster veya ürün yoksa farklı mesaj
- Boş state: "Ürün bulunamadı" yerine admin için uyarı, kullanıcı için "Yakında" veya gerçek boş mesaj
- Loading skeleton ekle (API beklerken boş state gösterme)

Test:
- /api/products → en az 1 ürün dönmeli (hedef 900+)
- Sayfa ürün grid'i göstermeli
- "X ürün" sayacı gerçek sayıyı yansıtmalı

### 2. Ürün detay sayfaları 404 veriyor
Sorun: /yourpoodle/urun/808 → "Aradığınız sayfayı bulamadık" (404)
Ana sayfa ve Mama Bul'dan gelen ürün linkleri kırık.

Yapılacaklar:
- /yourpoodle/urun/:id veya /yourpoodle/urun/:slug route'unu düzelt
- Ürün detay sayfası göstermeli:
  * Ürün görseli (kırık img olmasın, CDN'den)
  * Ürün adı (H1)
  * Fiyat (₺)
  * Marka, kategori
  * Kısa açıklama
  * Stok durumu
  * "Sepete Ekle" butonu
  * Breadcrumb: Ana Sayfa > Mağaza > [Kategori] > [Ürün]
- Ürün bulunamazsa anlamlı 404 (mevcut genel 404 yerine "Bu ürün artık satışta değil" + mağazaya dön)
- Mama Bul ve ana sayfadaki ürün linklerinin doğru URL'e gitmesini sağla

### 7. Schema / Structured Data düzelt
Mevcut:
- BreadcrumbList ✓ (koru)
- WebApplication ✗ (yanlış tip — kaldır)

Ekle:
A) CollectionPage + ItemList (mağaza listesi):
{
  "@context": "https://schema.org",
  "@type": "CollectionPage",
  "name": "Poodle Mağazası",
  "description": "Toy Poodle için mama, ödül, aksesuar ve bakım ürünleri",
  "url": "https://www.yourpoodle.com/yourpoodle/magaza",
  "mainEntity": {
    "@type": "ItemList",
    "numberOfItems": [gerçek ürün sayısı],
    "itemListElement": [
      {
        "@type": "ListItem",
        "position": 1,
        "item": {
          "@type": "Product",
          "name": "[ürün adı]",
          "image": "[ürün görsel URL]",
          "brand": { "@type": "Brand", "name": "[marka]" },
          "offers": {
            "@type": "Offer",
            "price": "[fiyat]",
            "priceCurrency": "TRY",
            "availability": "https://schema.org/InStock",
            "url": "https://www.yourpoodle.com/yourpoodle/urun/[slug]"
          }
        }
      }
    ]
  }
}

B) Her ürün detay sayfasında ayrı Product schema (Offer, brand, image, description)

C) WebSite SearchAction'ı mağaza aramasına yönlendir:
"urlTemplate": "https://www.yourpoodle.com/yourpoodle/magaza?q={search_term_string}"
(şu an /bilgi?q= yönlendiriyor — yanlış)

### 16. 768px breakpoint düzelt
Sorun: 768px'te sayfa mobil layout'a geçiyor (bottom nav + hamburger).
1024px tablet için 2 sütunlu ürün grid kullan.

Breakpoint önerisi:
- ≥1280px: 4 sütun grid
- 1024-1279px: 3 sütun
- 768-1023px: 2 sütun, üst nav koru (bottom nav GİZLE)
- <768px: 1-2 sütun, bottom nav göster
