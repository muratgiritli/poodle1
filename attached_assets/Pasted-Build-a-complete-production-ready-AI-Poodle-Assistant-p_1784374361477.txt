Build a complete, production-ready "AI Poodle Assistant" page for a pet care website called YourPoodle. This is a FULL standalone AI chat page — NOT a landing page with a sidebar widget. The chat experience must be the primary focus, similar to ChatGPT/Claude, but specialized ONLY for Toy Poodle dogs.

---

## PROJECT GOAL

Create a modern, responsive AI assistant page with:
- Desktop layout (1440px+)
- Tablet layout (768px–1024px)
- Mobile layout (320px–767px)

The page must feel like a real AI chat product: clean, fast, intuitive, and pet-owner friendly. All content, examples, and assistant behavior must be Toy Poodle–specific only (not generic dogs, not other Poodle sizes like Miniature or Standard).

---

## TECH STACK (use unless project already has conventions)

- React + TypeScript (or Next.js App Router if starting fresh)
- Tailwind CSS for styling
- Lucide React for icons
- Fully responsive with mobile-first CSS
- No external UI library required unless already in project — build custom components matching the mockup

## RESPONSIVE BEHAVIOR

### Desktop (≥1024px)
- 3-column: sidebar (240px) + chat (flex) + optional profile panel (280px)
- All elements visible
- Suggestion cards in 3×2 grid

### Tablet (768px–1023px)
- Sidebar collapses to hamburger drawer OR icon-only rail (64px)
- Profile panel hidden, accessible via header
- Chat takes full remaining width
- Suggestion cards 2×3 grid
- Input bar full width of chat column

### Mobile (≤767px)
- Single column, full-screen chat
- Hamburger menu (top-left) opens sidebar drawer overlay
- Header: logo + title + profile avatar only
- Welcome illustration smaller
- Suggestion cards: horizontal scroll row OR stacked 1-column
- Messages: max-width 85%
- Input bar: fixed bottom, full width, safe-area padding
- Sidebar drawer: slides from left with backdrop overlay

Test and verify at: 375px (iPhone), 768px (iPad), 1440px (desktop).

## FUNCTIONAL REQUIREMENTS

1. **Chat state management**
   - messages array: { id, role: 'user' | 'assistant', content, timestamp }
   - activeChatId, chatHistory list
   - New chat clears messages to welcome state
   - Clicking history item loads that chat

2. **Send message flow**
   - User types or clicks suggestion → message added → show typing indicator (3 dots animation) → AI response after 1–2s delay
   - For now, AI responses can be rule-based/mock responses tailored to Toy Poodle keywords (nutrition, grooming, training, health, behavior)
   - Structure mock AI to mention "Toy Poodle" specifically in answers

3. **Category shortcuts**
   - Clicking sidebar category pre-fills or sends a category-specific starter question

4. **Profile personalization**
   - Store profile in local state (name, age, weight)
   - AI welcome message references profile: "Luna için size nasıl yardımcı olabilirim?"

5. **Accessibility**
   - Proper aria labels on buttons
   - Keyboard navigable
   - Focus states visible
   - Color contrast WCAG AA

6. **Performance**
   - Smooth scroll in chat
   - No layout shift when input grows
   - Sidebar drawer doesn't break scroll on mobile
