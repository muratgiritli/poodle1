### 1. Kullanım Şartları ve Gizlilik Politikası tıklanamıyor
Sorun: Metin mor ve kalın görünüyor ama <a> değil, <span>:
"Devam ederek Kullanım Şartlarını ve Gizlilik Politikasını kabul etmiş olursunuz."
Kullanıcı şartları okuyamıyor — KVKK/GDPR uyumluluk riski.

Düzelt:
- <span> → <a href="/yourpoodle/kullanim-sartlari">Kullanım Şartlarını</a>
- <span> → <a href="/yourpoodle/gizlilik-politikasi">Gizlilik Politikasını</a>
- Linkler yeni sekmede açılabilir (target="_blank" rel="noopener")
- /yourpoodle/kullanim-sartlari ve /yourpoodle/gizlilik-politikasi sayfalarına GERÇEK yasal metin ekle (şu an boş/404 fallback)

### 2. Google ile Devam Et çalışmıyor
Sorun: Butona tıklanınca hiçbir şey olmuyor; OAuth popup/redirect yok.

Düzelt:
- Google OAuth 2.0 akışını implement et (Firebase Auth / Supabase Auth / NextAuth — mevcut stack'e uygun)
- Buton tıklanınca: loading spinner + disabled state
- Başarılı giriş: returnUrl veya varsayılan /yourpoodle/club'a yönlendir
- Hata durumu: "Google girişi başarısız, tekrar deneyin" toast/mesaj
- Google Cloud Console'da authorized redirect URI doğru olmalı

### 3. returnUrl parametresi kullanılmıyor
Sorun: ?returnUrl=/yourpoodle/club URL'de var ama:
- Giriş sonrası yönlendirme yok
- Misafir butonu ana sayfaya (/) gidiyor, returnUrl'e değil

Düzelt:
- URL'den returnUrl query param'ını oku
- sessionStorage veya state'e kaydet
- Başarılı giriş/kayıt sonrası returnUrl'e yönlendir
- Güvenlik: returnUrl whitelist kontrolü (sadece yourpoodle.com domain)
- Misafir modunda da returnUrl'e git (guest izinli sayfalar için)
- returnUrl yoksa varsayılan: /yourpoodle/club veya /yourpoodle

### 4. Misafir akışı belirsiz
Sorun: "Misafir Olarak Devam Et" → ana sayfa (/). Guest session oluştuğu belli değil.

Düzelt:
- Guest token veya localStorage flag oluştur: { isGuest: true, expiresAt: ... }
- returnUrl varsa oraya yönlendir
- Club gibi sayfalarda "Misafir modundasınız — tam erişim için üye olun" banner
- Guest kısıtlamaları: beğeni/yorum/paylaşım → login wall
- Guest süresi: 24 saat veya session boyunca

  "isPartOf": { "@id": "https://www.yourpoodle.com/#website" },
  "potentialAction": {
    "@type": "RegisterAction",
    "target": {
      "@type": "EntryPoint",
      "urlTemplate": "https://www.yourpoodle.com/yourpoodle/giris",
      "actionPlatform": [
        "http://schema.org/DesktopWebPlatform",
