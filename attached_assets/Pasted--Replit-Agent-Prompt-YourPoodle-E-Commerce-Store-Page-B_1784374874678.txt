# Replit Agent Prompt: YourPoodle E-Commerce Store Page

Build a **fully responsive, production-quality e-commerce store page** for **YourPoodle** — a Turkish pet brand specializing in Poodle products. Match the provided design mockup as closely as possible. Use **React + Vite + Tailwind CSS** (or Next.js if preferred). All visible UI text must be in **Turkish**.

---

## Project Overview

**Brand:** YourPoodle  
**Page:** Store / Mağaza (`/magaza`)  
**Goal:** A polished, modern e-commerce landing + product listing page for Poodle food, treats, accessories, and care products.

---

## Design System

### Colors
| Token | Usage |
|-------|--------|
| **Primary Purple** | `#7C3AED` or similar vibrant purple — logo, primary buttons, active nav, prices, accents |
| **Purple Dark** | Hover states, footer background |
| **Orange** | Secondary CTA buttons (e.g. "Mama Bul") — `#F97316` or similar |
| **White** | Main background |
| **Light Gray** | `#F9FAFB` / `#F3F4F6` — section backgrounds, cards |
| **Border Gray** | `#E5E7EB` — inputs, dividers |
| **Text Dark** | `#111827` — headings |
| **Text Muted** | `#6B7280` — body, subtitles |

### Typography
- Modern sans-serif: **Inter**, **Plus Jakarta Sans**, or **DM Sans**
- Headings: bold, tight letter-spacing
- Body: regular, readable line-height

### UI Style
- Rounded corners: `rounded-xl` / `rounded-2xl` on cards, buttons, inputs
- Soft shadows on cards and header
- Smooth hover transitions (150–200ms)
- Consistent spacing: 4px grid system
- Mobile-first, fully responsive

## Technical Requirements

### Stack
- **React 18+** with **Vite**
- **Tailwind CSS** for styling
- **Lucide React** or **Heroicons** for icons
- Optional: **Framer Motion** for subtle animations

### Data & State
- Mock product data in a `products.js` or JSON file
- Cart state (React Context or Zustand): add to cart, badge count
- Favorites toggle (local state)
- Filter chips update visible products (client-side)
- Sort dropdown works on product list

### Assets
- Use **Unsplash / Pexels** or placeholder images for products and Poodle hero photo
- Paw icon via Lucide (`PawPrint`) or custom SVG

### Responsive Breakpoints
- Mobile: < 768px — hamburger nav, stacked hero, 1-col products
- Tablet: 768–1024px — 2-col products
- Desktop: > 1024px — full layout as mockup

### Accessibility
- Semantic HTML (`header`, `nav`, `main`, `section`, `footer`)
- Alt text on all images
- Keyboard-navigable accordion and buttons
- Sufficient color contrast

### Performance
- Lazy-load below-fold images
- Optimize images (WebP where possible)
- No external UI libraries beyond Tailwind
