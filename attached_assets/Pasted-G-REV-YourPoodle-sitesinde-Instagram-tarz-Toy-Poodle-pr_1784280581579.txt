1. VERİ MODELİ (DB SCHEMA)
═══════════════════════════════════════
Yeni tablolar ekle (Drizzle/schema):

dogs {
  id, userId (FK users), slug (unique), name,
  breed: 'toy' | 'miniature',
  birthDate, weightKg, color, gender,
  city, district,
  bio (max 150 char),
  avatarUrl,
  isPublic: boolean (default true),
  isPrivate: boolean (default false),
  followerCount, followingCount, postCount,
  createdAt, updatedAt
}

dog_photos { id, dogId, url, caption, order, createdAt }

club_posts {
  id, dogId (FK dogs — ZORUNLU), userId,
  content, imageUrls (json array, max 4 carousel),
  hashtags (json array),
  likeCount, commentCount,
  visibility: 'public' | 'followers',
  createdAt
}

club_post_likes { id, postId, userId, createdAt }
club_post_comments { id, postId, userId, content, createdAt }

dog_follows {
  id, followerUserId, dogId,
  status: 'active' | 'pending' | 'rejected',
  createdAt
}

notifications {
  id, userId, type, actorUserId, dogId, postId,
  message, isRead, createdAt
}
-- type: 'follow_request' | 'follow_accept' | 'like' | 'comment' | 'new_follower'

Mevcut club_posts varsa dogId kolonu ekle (migration).

10. API ENDPOINTS
═══════════════════════════════════════
POST   /api/dogs                    → profil oluştur (auth)
GET    /api/dogs/:slug              → public profil
PUT    /api/dogs/:slug              → güncelle (owner)
DELETE /api/dogs/:slug              → sil (owner)
GET    /api/dogs                    → dizin (filter, search, sort)
GET    /api/dogs/check-slug/:slug   → slug müsait mi?

GET    /api/club/feed               → takip edilenlerin postları (paginated)
POST   /api/club/posts              → paylaşım (auth, dogId zorunlu)
DELETE /api/club/posts/:id          → sil (owner)
POST   /api/club/posts/:id/like     → beğen/beğenme
GET    /api/club/posts/:id/comments → yorumlar
POST   /api/club/posts/:id/comments → yorum ekle

POST   /api/dogs/:slug/follow       → takip / istek gönder
DELETE /api/dogs/:slug/follow       → takipten çık
POST   /api/dogs/:slug/follow/accept → kabul (owner)
POST   /api/dogs/:slug/follow/reject → red (owner)
GET    /api/dogs/:slug/followers    → takipçiler
GET    /api/dogs/:slug/following    → takip edilenler

GET    /api/notifications           → bildirimler (auth)
PUT    /api/notifications/:id/read  → okundu
GET    /api/notifications/unread-count → badge

GET    /api/dogs/:slug/og-card      → story kartı PNG (1080x1920)
GET    /api/club/explore            → keşfet
GET    /api/club/stories            → hikaye şeridi (24 saat)
