State:
  step: "phone" | "otp"           // default "phone", mockup shows "otp" state too
  phone: string                    // digits only, 10 chars e.g. "5321234848"
  otp: string[4]                   // ["4","8","2","1"] in demo
  smsSent: boolean
  countdown: number                // seconds, default 60, starts after send
  termsAccepted: boolean           // required checkbox
  marketingAccepted: boolean       // optional checkbox
  isLoading: boolean
  maskedPhone: string              // "+90 532 *** ** 48"

Functions:

  formatPhoneDisplay(raw):
    Format as "5XX XXX XX XX" while typing

  validatePhone(phone):
    Must be 10 digits, start with 5 (Turkish mobile)
    IF invalid → toast "Geçerli bir cep telefonu numarası girin"

  sendSMS():
    IF !validatePhone → return
    IF !termsAccepted → toast "Lütfen sözleşmeleri kabul edin"
    Set smsSent = true, step = "otp"
    Set maskedPhone from last 2 digits
    Start countdown = 60
    showToast("Doğrulama kodu gönderildi ✓")
    Mock OTP code stored: "4821" (for demo verification)

  verifyOTP():
    IF otp joined !== "4821" (mock) → toast "Geçersiz doğrulama kodu"
    ELSE:
      setAuthenticated(true) in AuthContext
      showToast("Hoş geldiniz! ✓")
      navigate(returnUrl || "/magaza")

  resendOTP():
    IF countdown > 0 → disabled
    ELSE reset countdown = 60, showToast("Kod yeniden gönderildi")

  changePhone():
    step = "phone", smsSent = false, otp = ["","","",""], countdown = 0

  onOTPChange(index, digit):
    Only allow 0-9, single char
    Auto-focus next box
    Auto-submit when 4 digits filled (optional)

Countdown timer:
  useEffect interval, decrement every 1s
  Format: "00:42" (mm:ss padded)
  Display: "Kodu tekrar gönder: {countdown}"
