## TASK 1 — Lock Down Admin Panel (CRITICAL)

**Problem:** `/admin` is publicly accessible with username/password login. `POST /api/admin/login` has no rate limiting.

**Do:**

1. Protect `/admin` and all `/api/admin/*` routes with:
   - **Rate limiting:** max 5 failed login attempts per IP per 15 minutes; return `429 Too Many Requests` with `Retry-After` header.
   - After 3 failed attempts, require **CAPTCHA** (Cloudflare Turnstile or hCaptcha — use env var `CAPTCHA_SECRET_KEY`).
   - Lock account/IP temporarily after 10 failed attempts (30 min).

2. Add **2FA support** for admin accounts (TOTP via `speakeasy` or similar) — mandatory for admin role after first login.

3. Move admin UI to a **non-obvious path** OR add **IP allowlist** via env var `ADMIN_ALLOWED_IPS` (comma-separated). If IP not in list, return `403` before showing login form.

4. Ensure admin session uses:
   - `httpOnly`, `Secure`, `SameSite=Strict` cookies
   - Session expiry: 8 hours max
   - Regenerate session ID on login

5. Log all admin login attempts (success/fail) with timestamp, IP, user-agent — store in DB or file log. Never log passwords.

6. Return generic error on failed login: `"Invalid credentials"` — do not reveal whether username exists.

**Verify:** 6 wrong passwords from same IP → 429. Admin panel inaccessible from non-allowlisted IP (if configured).

## TASK 2 — Secure Contact Form API (CRITICAL)

**Problem:** `POST /api/contact-messages` accepts unauthenticated requests with no rate limit or CAPTCHA. Response leaks internal fields (`id`, `isRead`, `createdAt`).

**Do:**

1. Add **rate limiting:** max **3 submissions per IP per hour**.
2. Add **CAPTCHA verification** (same provider as admin) — reject if CAPTCHA fails.
3. Add **honeypot field** `website` (hidden via CSS) — if filled, silently reject (return 200 but do not save).
4. Change response to only:
   ```json
   { "success": true, "message": "Mesajınız alındı." }
   ```
   Never return `id`, `isRead`, or internal DB fields to the client.
5. Validate inputs server-side:
   - `name`: 2–100 chars, no HTML
   - `phone`: Turkish phone format regex
   - `email`: optional, valid email
   - `message`: 10–2000 chars, strip HTML tags
6. Sanitize all inputs before DB insert (`DOMPurify` server-side or manual strip).
7. Keep `GET /api/admin/contact-messages` protected (must stay 401 without admin auth).

**Verify:** 4 rapid POSTs → 4th returns 429. Response has no internal fields.

## TASK 3 — Rate Limit All Auth Endpoints (HIGH)

**Problem:** No rate limiting on login, register, magic link.

**Do:**

Apply rate limits to:

| Endpoint | Limit |
|----------|-------|
| `POST /api/auth/login` | 10 req / 15 min / IP |
| `POST /api/auth/register` | 5 req / hour / IP |
| `POST /api/auth/magic-link` | 3 req / hour / IP + email |
| `POST /api/auth/forgot-password` | 3 req / hour / IP + email |
| OAuth callbacks | 20 req / 15 min / IP |

- Return `429` with clear message.
- Add CAPTCHA after 3 failed login attempts.
- Magic link: always return same response whether email exists or not:
  ```json
  { "success": true, "message": "If this email is registered, a link has been sent." }
  ```
  Prevent email enumeration.

**Verify:** Spam magic-link requests → blocked after 3rd.

## TASK 4 — Harden Content-Security-Policy (HIGH)

**Problem:** CSP allows `'unsafe-inline'`, `'unsafe-eval'`, and `img-src https:` (any domain).

**Do:**

1. Remove `'unsafe-eval'` from `script-src` entirely.
2. Replace `'unsafe-inline'` in `script-src` with **nonce-based** or **hash-based** CSP. If not feasible immediately, use strict-dynamic with nonce on inline scripts.
3. Restrict `img-src` to:
   ```
   img-src 'self' data: blob: https://www.yourpoodle.com https://www.google-analytics.com https://www.googletagmanager.com;
   ```
   Add product CDN domain if used.
4. Add `object-src 'none'`.
5. Add `upgrade-insecure-requests`.
6. Keep `frame-ancestors 'self'`.
7. Test all pages (home, rehber, AI asistan, club, giris, magaza) — no CSP console errors.

**Verify:** Browser DevTools → no CSP violations on main flows.
